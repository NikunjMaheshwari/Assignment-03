# Assignment-03

## 📌 Project Description

This project is a simple interactive web page built using **HTML, CSS, and JavaScript**.
It demonstrates basic DOM manipulation and event handling.

---

## 🎯 Features

* Displays a greeting message
* Takes user input and updates greeting dynamically
* Four interactive color boxes (Red, Blue, Green, Yellow)
* Changes box background color on click
